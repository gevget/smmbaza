# SMMБаза — landing page

Статический русскоязычный лендинг для продукта SMMБаза: автопостинг VK, супергруппы и отчёты со скриншотами.

## Локальный запуск

Проект не использует сборщик или обязательные зависимости. Для локального просмотра:

```powershell
python -m http.server 4175
```

Откройте `http://localhost:4175/`.

## Структура

- `index.html` — семантическая разметка страницы и SEO metadata.
- `src/styles.css` — токены, адаптивная сетка и состояния интерфейса.
- `src/main.js` — иконки, media slots, калькулятор, меню, слайдер, lightbox, форма и аналитика.
- `src/content/media.js` — единый manifest изображений.
- `src/content/site-content.js` — базовые тексты и параметры калькулятора.
- `src/config/site-config.js` — production URL и точки интеграций.
- `public/media/` — утверждённые и сгенерированные изображения.
- `scr/` — реальные скриншоты продукта.

## Перед публикацией

Заполните значения в `src/config/site-config.js`:

- `SITE_URL`;
- `VK_AUTH_URL`;
- `DEMO_FORM_ENDPOINT`;
- `PRIVACY_URL` и `TERMS_URL`;
- `MARKET_URL`;
- `ANALYTICS_ID`;
- `OG_IMAGE_URL`.

Сайт публикуется через GitHub Pages по адресу `https://gevget.github.io/smmbaza/`. Форма честно работает как демо и не отправляет данные, пока не будет подключён production endpoint.

## Временный контент

Тексты и значения, которые требуют подтверждения команды, отмечены `*` прямо на странице. Перед production замените их на подтверждённые цифры, условия подключения, срок ответа и юридические ссылки.

## QA

Проверяйте минимум следующие ширины: 375, 390, 430, 768, 1024, 1280, 1440 и 1920 px. Отдельно проверьте слайдер, lightbox, калькулятор, мобильное меню, валидацию формы и отсутствие горизонтального скролла.
